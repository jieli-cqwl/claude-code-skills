# 复杂模式输出规范

> 规则 > 3 条或跨模块时使用。输出 master.md + manifest.json + units/ 目录。

---

## master.md 模板

```markdown
# PRD: [功能标题]

**功能名**: {feature_name}
**产出时间**: YYYY-MM-DD
**模式**: 复杂（UNIT 拆解）

---

## 业务背景
[为什么需要这个功能]

## 用户故事
- 作为 [角色]，我希望 [动作]，这样 [价值]
- 作为 [角色]，我希望 [动作]，这样 [价值]

## 业务流程

### 正常路径
触发事件 → 步骤 1 → 步骤 2 → ... → 结束状态

### 异常路径
- [异常触发条件] → [系统响应] → [结束状态]

## UNIT 索引

| UNIT | 标题 | 依赖 |
|------|------|------|
| UNIT-001 | [标题] | 无 |
| UNIT-002 | [标题] | UNIT-001 |

## 全局排除项
- [明确不做的事情]

## 全局技术约束
- [来自项目规范的约束]

## 交接项
- UNIT 数量: X 个
- 规则总数: X 条
- 依赖深度: 最大 N 层
```

- [输入] → [期望输出]

- [输入] → [期望错误/拒绝]
- [输入] → [期望错误/拒绝]

### 边界
- [边界条件] → [期望行为]
- [边界条件] → [期望行为]

## 完整示例

需求：「实现带权限控制的文档协作系统」

### master.md 示例

```markdown
# PRD: 文档协作系统

**功能名**: doc-collab
**产出时间**: 2026-02-28
**模式**: 复杂（UNIT 拆解）

---

## 业务背景
团队需要在线协作编辑文档，支持不同角色的权限控制，替代当前的共享文件夹模式。

## 用户故事
- 作为文档所有者，我希望控制谁能查看和编辑我的文档
- 作为协作者，我希望看到文档的最新版本和变更历史
- 作为管理员，我希望管理全局的文档访问策略

## 业务流程

### 正常路径
1. 用户创建文档 → 自动成为 Owner
2. Owner 邀请协作者 → 指定角色（Viewer/Editor）
3. 协作者编辑文档 → 自动保存版本
4. Owner 可随时调整权限或撤销访问

### 异常路径
- 邀请不存在的用户 → 返回错误提示，不创建权限记录
- 协作者编辑时 Owner 撤销权限 → 当前编辑中止，提示"权限已被撤销"
- 文档 Owner 注销账号 → 文档所有权转移至管理员

## UNIT 索引

| UNIT | 标题 | 依赖 |
|------|------|------|
| UNIT-001 | 文档 CRUD | 无 |
| UNIT-002 | 角色权限模型 | UNIT-001 |
| UNIT-003 | 协作者邀请 | UNIT-001, UNIT-002 |
| UNIT-004 | 版本历史 | UNIT-001 |
| UNIT-005 | 权限变更 | UNIT-002, UNIT-003 |

## 全局排除项
- 不做实时协同编辑（WebSocket）
- 不做文档导出（PDF/Word）
- 不做全文搜索

## 全局技术约束
- RESTful API，JSON 响应
- 权限校验在中间件完成
- 版本存储使用 append-only 模式

## 交接项
- UNIT 数量: 5 个
- 规则总数: 预计 12-15 条（分布在各 UNIT 中）
- 依赖深度: 最大 2 层
```

### UNIT 文件示例

```markdown
# UNIT-001: 文档 CRUD

## 背景
文档是协作系统的核心实体，需要支持创建、读取、更新、删除的基本操作。

## 规则描述
用户可以创建、查看、编辑和删除自己的文档。

## 验收标准

### 正例
- 创建文档：`POST /docs {title: "设计稿", content: "..."}` → 201，返回文档 ID
- 查看文档：`GET /docs/{id}` → 200，返回文档内容
- 更新文档：`PUT /docs/{id} {content: "新内容"}` → 200，返回更新后的文档

### 反例
- 标题为空：`POST /docs {title: "", content: "..."}` → 422，提示"标题不能为空"
- 文档不存在：`GET /docs/999` → 404，提示"文档不存在"
- 删除他人文档：`DELETE /docs/{other_id}` → 403，提示"无权限"

### 边界
- 标题最大 200 字符 → 超过返回 422
- 内容最大 1MB → 超过返回 413

## 依赖
- 依赖 UNIT: 无
- 依赖数据: User 实体（已有）

## 排除项
- 不处理文档模板
- 不处理批量操作
```
