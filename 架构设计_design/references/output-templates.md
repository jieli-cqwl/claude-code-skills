# 输出模板

## 精简版模板

适用条件：需求规则 <= 3 条且涉及单模块

```markdown
# handoff_design.md

## Goals / Non-Goals
### Goals
- [G1: ...]
### Non-Goals
- [NG1: 本可以成为目标但被排除的事项...]

## 输入分析
[扫描现有代码的发现 + 需求规则逐条理解]

## 架构视图（可选）
> 涉及多模块交互时建议绘制，单模块内部改动可省略

## 决策
[关键技术选型及方案对比]

## 产出
### 模块划分
### 接口清单
### 数据模型

## Open Questions
[待确认假设，无则标"无待确认项"]

## 覆盖表
[需求规则 -> 设计产出 -> 覆盖状态]

## 交接项
```

## 完整版模板

适用条件：需求规则 > 3 条、跨模块或架构变更

```markdown
# handoff_design.md

## Goals / Non-Goals
### Goals
- [G1: ...]
### Non-Goals
- [NG1: 本可以成为目标但被排除的事项...]

## 输入分析
[扫描现有代码的发现 + 需求规则逐条理解]

## 架构视图
[Mermaid C4 System Context 图 + Container 图，强制要求]

## 决策
[关键技术选型及方案对比]

## 产出
### 模块划分
### 接口清单
### 数据模型

## 横切关注点
[安全、隐私、可观测性、错误监控]

## Open Questions
[待确认假设]

## 成功指标
[可量化的验收标准]

## 覆盖表
[需求规则 -> 设计产出 -> 覆盖状态]

## 交接项
```
