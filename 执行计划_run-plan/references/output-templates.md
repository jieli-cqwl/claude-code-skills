# 输出模板

## 执行输出模板

```markdown
# handoff_run.md

## 输入分析
[Plan 任务理解 + Design 接口理解]

## 决策
[任务执行顺序、实现策略、测试策略]

## 产出
TEST_CMD: <命令>

### 执行记录

### Task-1: [标题]
- 测试先行: [测试文件和用例]
- 红阶段: [测试运行失败输出]
- 实现: [修改的文件]
- 绿阶段: [测试运行通过输出]
- 全量测试: [全量测试结果]
- Commit: feat(Task-1): [描述]

### Task-2: [标题]
...

### Task-Commit 对照表
| Task | Commit | 含测试 | 状态 |

### 交接项
- commit 列表（含 hash）
- 测试运行结果摘要
- 已知遗留问题
- BLOCKED 任务（如有）
```

## Plan 评审输出模板

```markdown
## 输入分析
[计划文档可执行性分析]

## 决策
[评审结论依据]

## 产出
REVIEW: PLAN_OK
（如有问题则输出：REVIEW: PLAN_ISSUE）

### 评审摘要
[总结评审结果]

### Issues（如有）
1. [ISSUE-1] [具体问题]
   - 类型：[文件路径/AC可测性/依赖拓扑/任务粒度/设计一致性]
   - 建议：[具体修改建议]

### 检查明细
[逐项检查结果]
```
